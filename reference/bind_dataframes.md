# Name And Bind Dataframes

Name And Bind Dataframes

## Usage

``` r
bind_dataframes(data, file_names)
```

## Arguments

- data:

  A list of dataframes.

- file_names:

  A character vector of file names from which each dataframe was
  derived, where the position of each file name in the character vector
  matches the position of the dataframe in the list.

## Value

A tibble.
