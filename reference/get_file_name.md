# Get The Names Of Files In A Folder

Given a file path and a folder name, return the name of any files in
that folder.

## Usage

``` r
get_file_name(file_path = tere::get_file_storage_path(), folder_name)
```

## Arguments

- file_path:

  The path of the file.

- folder_name:

  The name of the folder housing the files.

## Value

File names as a named fs_path character vector.
