# Update SharePoint List Items

Update SharePoint List Items

## Usage

``` r
update_list_items(site_name, list_name, item_ids, ...)
```

## Arguments

- site_name:

  Name of SharePoint site to which you want to connect.

- list_name:

  Name of the List to which you are connecting.

- item_ids:

  Character vector containing a list of IDs to SharePoint List items.

- ...:

  Named character vector.

## Value

Message to the console
