# Retrieve SharePoint List Items

Retrieve SharePoint List Items

## Usage

``` r
get_list_items(site_name, list_name)
```

## Arguments

- site_name:

  The name of the SharePoint site to which you wish to connect, which
  can be found in the site's homepage URL.

- list_name:

  The name of the SharePoint List you wish to retrieve.

## Value

A data frame.
